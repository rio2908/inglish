# Журнал изменений

Записи описывают результат работы, а не заменяют спецификацию. Новые исправления дописываются в начало соответствующей даты с фактическими проверками.

## 2026-10-16 — повторный аудит игровой логики

- Регрессионными тестами воспроизведены пропуск карточки повторным «Дальше», начисление ответа после выхода из урока и перехват экспорта скрытой областью питомца на экране конфликта. Обработчики теперь проверяют экран/фазу, кликабельные области привязаны к отрисованному экрану/игроку, повторный ввод до перерисовки блокируется.
- У старых данных с потерянным/отставшим номером раунда восстановление могло отбросить ответ из раунда 0 или переиспользовать старый номер. Нормализация восстанавливает счётчик по историям ответов, а модель отклоняет недопустимый раунд и неизвестный ID до изменения данных. Корректные раунды и формат сохранений не изменены.
- Добавлен сквозной сценарий всех шести существ и повторного выращивания: 900 выученных слов, порядок открытия, короткие/итоговые проверки, возврат ожидающего питомца, отсутствие лишнего открытия и неубывание общих знаний. Баланс и порог 7/10 не менялись.
- Полный прогон: **171 тест, OK** (pygame-ce 2.5.8, SDL dummy); `pyflakes`, `py_compile` и `git diff --check` прошли. Сквозной тест использует in-memory `PlayerStore`; отдельные тесты записи/перезапуска/миграции — временные каталоги. Визуально просмотрены экраны следующей карточки после двух кликов и конфликта сохранения. Настоящие профили не затрагивались; Android/APK и браузер этим прогоном не проверялись.

## 2026-10-15 — исправление выгрузки и загрузки профиля на Android

- Тестом воспроизведён откат 8 → 4 из-за устаревшей копии того же профиля. Добавлены ревизии, `StaleProfileError`, собственный токен каждого `GameApp`, проверка на возврате фокуса и экран безопасного восстановления без автоматического слияния. На нём доступны только выгрузка локальной копии и загрузка свежего состояния, без активных кнопок сада за модальным экраном. Число выученных при обычной игре и переносе отдельно проверяется на неубывание.
- Приватный документ игроков мигрирует v1 → v2 с сохранением ID/имён/игр; устаревший клиент не записывает документ v2. Форматы переносимых JSON v1/v2 не менялись. Только подтверждённое восстановление копии может явно заменить более свежую игру; оно инвалидирует прежние токены.
- Android TTS получает типизированные Java-аргументы и fallback на legacy overload. Ошибки JNI не выводятся ребёнку; детали пишутся в диагностику/logcat. Подсказка о скачивании английского голоса даётся при отрицательном статусе языка, а не при любой программной ошибке. Исправлены повторная попытка после неудачной инициализации и отмена отложенных реплик при остановке. После успешного прослушивания старая ошибка исчезает. Это проверено имитацией Java API, не реальным телефоном.
- Воспроизведён регрессионными тестами сброс незаконченного урока перед экспортом: «В сад» очищал `lesson`, а возврат начинал новый раунд. Теперь сохраняется карточка и фаза, пауза не меняет care и повторно не засчитывает ответ.
- Исправлена перезапись Android-документа: запрашивается `wt`, seekable-файл явно обрезается до нового размера. Удалён сценарий с остатком прежнего длинного JSON; потоковые дескрипторы также поддерживаются.
- Результаты коротких проверок ожидающего питомца сохраняются при нормализации повторного выращивания; вид/цикл и его собственный прогресс учитываются отдельно от активного яйца.
- Занятый picker не принимает второй запрос и не меняет владельца первой операции; посторонние/запоздалые Android callbacks игнорируются, ошибка открытия browser picker позволяет повторить запрос.
- Добавлен полный маршрут файл → Android-мост → подтверждение → `PlayerStore` → новый `GameApp` для десяти фаз состояния; отдельно проверены существующий игрок, соседний профиль и legacy-копия без владельца. В тестах используются реальные JSON и OS-дескрипторы, Activity/ContentResolver имитируются; настоящие профили не затрагиваются.
- Полный прогон в `.venv` с pygame-ce 2.5.8: **159 тестов, OK**, без пропущенных UI-модулей. `pyflakes` и `py_compile` изменённых модулей прошли; `git diff --check` не выявил ошибок пробелов.
- Проверены реальные JSON/OS-дескрипторы и новый запуск `GameApp` после переноса; системные Activity/ContentResolver и Java TTS API имитируются. До исправления новые регрессионные тесты воспроизводили потерю урока/истории, остаток старого файла, смену владельца занятого picker и откат 8 → 4.
- Визуально проверены SDL dummy-экраны конфликта сохранения, приостановленного урока с сохранённым счётчиком 8 и читаемой ошибки Android-озвучки без traceback. Настоящие профили не изменялись. APK/нативный диалог и звук на физическом Android не проверены; для подтверждения нужен новый APK и проверка на устройстве.

## 2026-10-15 — текущая разработка прототипа

### Игровые возможности

- Добавлен личный словарик выученных слов с произношением, переводом, поиском, фильтрами и повторной озвучкой перед итоговым тестом. Чтение не меняет прогресс и не обходит порог 70%; это защищено отдельными pure/UI-тестами.
- Уточнена нормализация раундов: boolean `true` не считается номером учебного раунда; дубли и некорректные данные не создают ложные выученные записи в словарике. Границы роста читаются из общей константы.
- Название EnglishCraft; идентификатор Android и прежние имена файлов/форматы оставлены совместимыми.
- Шесть последовательных существ и шесть непересекающихся наборов по 150 карточек, всего 900 ID.
- Индивидуальные стадии рисунков, возрастное поведение, пиксельные сердечки, свои развивающиеся биомы.
- Осмысленные картинки слов вместо питомца; для служебных слов — короткое правило только о текущем слове. `is/are/has/have` проверяются в предложениях.
- Подсветка примеров теперь фокусируется на изучаемом местоимении/слове, а не автоматически на стоящей рядом глагольной форме; регрессионный тест проверяет пример `I am happy`.
- По подтверждённому выбору пользователя рост распределён по 30 словам: вылупление на 30, превращения на 60/90/120. Добавлены сохраняемые поздравления со старым и новым видом.
- Четыре игры по возрастам, уход и общий сад без офлайн-штрафа.
- Проверки каждых 30 слов, очередь ошибок и статистика; итоговый тест перед новым видом не ниже 7/10.
- Повторное выращивание через кнопку-яйцо: взрослый остаётся рядом, ожидающий питомец сохраняется и возвращается; история циклов не теряется.

### Игроки и данные

- Регистрация и выбор локального игрока, как в MathCraft, без сетевого аккаунта; отдельные имена игрока и питомца.
- `PlayerStore` записывает только выбранного владельца, мигрирует общий прогресс в «Сохранённую игру» и не даёт регистрации затереть повреждённый файл.
- Экспорт выбранного игрока с идентификатором; импорт учитывает владельца, legacy-копии и смену игрока до асинхронного callback.
- Смена игрока сохраняет незаконченный урок/тест/поздравление и очищает transient-состояния UI и звук.
- После выхода активный `game` сбрасывается в несохраняемый пустой образец, чтобы справка до входа не использовала биом и стадию прежнего ребёнка; тест проверяет отсутствие остаточного активного состояния.

### Инструкция и сопровождение

- Добавлена постраничная справка с основных экранов, включая вход и регистрацию.
