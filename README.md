# EnglishCraft

Для разработчиков и агентов: [AGENTS.md](AGENTS.md), [спецификация игры](docs/GAME_DESIGN.md), [архитектура](docs/ARCHITECTURE.md), [проверки](docs/DEVELOPMENT.md), [журнал изменений](docs/CHANGELOG.md). После каждого исправления затронутая документация и журнал обновляются вместе с кодом.

Детская игра для Android: шесть питомцев со своими наборами по 150 английских слов и коротких фраз — всего 900 разных карточек. Пять стадий роста, вылупление, кормление, игры, уход, сад и зоопарк. Графика — крупные квадратные пиксели с видимой клеточной сеткой.

Каждый набор разбит на десять глав по 15 карточек. У сниффера — первые слова, животные и цвета; у аксолотля — счёт, тело, вода, еда и вежливые слова; у лисы — одежда, погода, лес, город и транспорт; у пчелы — школа, творчество, кухня и музыка; у черепахи — спорт, путешествия и животные; у эллея — дом, семья, чувства, распорядок дня и разговорные фразы. Это подборка повседневной детской лексики, а не частотный рейтинг. Артикли отдельно не изучаются. Русская запись произношения приблизительна; образец звучания даёт английская озвучка. Данные находятся в `words.py` и `curricula.py`.

Для зависимых форм и служебных слов есть контекстные подсказки (`grammar.py`): короткое правило и два переведённых примера с подсветкой изучаемого слова. Например, карточка `is` объясняет только его употребление с `he/she/it`, без таблицы других форм; на карточке `I` выделяется местоимение, а не соседний глагол. Для `is`, `are`, `has`, `have` вопросы в уроках, коротких проверках и итоговом тесте требуют вставить форму в предложение (`She ___ happy`, `We ___ a ball`), а не угадывать один перевод. После ответа показывается правильное предложение и правило. Местоимения, `my/your`, `can`, предлоги, союзы и некоторые фразы тоже сопровождаются примерами. `eat` отдельно объясняется как «кушать».

Правила на карточках объясняют только текущее слово: например, на карточке `is` нет сравнения с `am` или `are`. Два коротких примера тоже используют изучаемую форму, без дополнительных таблиц.

## Игра

- Яйцо постепенно трескается в течение первых 30 выученных слов; малыш появляется на 30 словах. Каждый правильный ответ сам по себе ещё не означает, что слово выучено.
- Слово считается выученным после правильного ответа в двух разных игровых раундах.
- Над лужайкой показано число слов до следующего превращения. Каждые 15 выученных слов дают снифферу возможность найти растение и открыть короткую историю.
- Превращения равномерны: яйцо и вылупление — 0–29 слов, малыш — 30–59, подросток — 60–89, взрослый — 90–119, финальная форма — от 120. После каждого превращения появляется поздравление со старым и новым видом; оно сохраняется до подтверждения, включая перезапуск и смену игрока.
- После вылупления нужно кормить питомца, играть с ним и убирать за ним. Потребности меняются только во время игры. Прогресс слов не пропадает.
- Через кнопку **ПРОФИЛЬ → ИЗМЕНИТЬ ИМЯ** можно назвать питомца (до 20 символов).

### Проверки и статистика слов

**СЛОВАРИК** в саду показывает выученные слова выбранного игрока с произношением, переводом и динамиком для повторного прослушивания. Есть поиск по английскому, русскому переводу и подсказке произношения, фильтры текущего питомца и ошибок, страницы и кнопка скрытия перевода для самопроверки. Перед итоговым тестом его можно открыть кнопкой **СЛОВА** в зоопарке; после неудачи — **ПОВТОРИТЬ СЛОВА**. Просмотр ничего не засчитывает и не снимает порог 70%; возврат сохраняет состояние теста.

После **30, 60, 90, 120 и 150 выученных слов** открывается короткая проверка из шести вопросов. В первую очередь попадают слова, в которых ребёнок ошибался на уроках или предыдущих проверках — даже если слово ещё не стало выученным. Свободные места заполняются случайными выученными словами. Чередуются выбор русского перевода и английского слова; незнакомые слова не добавляются. Проверка предлагается между карточками, а после неё урок продолжается с того же места. Её можно отложить и продолжить кнопкой в саду.

Ошибочные слова сохраняются в очереди повторения до правильного ответа в проверке; правильный ответ на обычном уроке не убирает их из этой очереди. Если ошибок больше шести, берём их по очереди, чтобы проверка оставалась короткой. Повторная ошибка переносит слово в конец очереди для будущих рубежей. В статистике такие слова отмечены «Повторить», а в обзоре видно их количество.

Каждый рубеж проверяется один раз. Результат показывает число правильных ответов и слова, которые стоит повторить. Ошибки не отменяют выученные слова, не влияют на превращения и потребности питомца. Незаконченная проверка и её результаты сохраняются между запусками и переносятся вместе с профилем.

Кнопка **СТАТИСТИКА** в саду открывает:

- **Обзор**: число выученных слов, слов в изучении и в очереди повторения ошибок, точность ответов, прогресс по главам.
- **Слова**: 150 карточек текущего питомца с переводом, статусом и числом верных ответов / попыток, включая уроки и проверки. Общее количество выученного в обзоре считается по всем 900 карточкам.
- **Проверки**: результаты пяти рубежей и последней итоговой проверки; можно переключаться между существами. Результаты повторного выращивания хранятся отдельными циклами, не затирая прежнюю историю.

История попыток подсчитывается с этой версии. Старые сохранения сохраняют статусы слов и открывают соответствующие проверки, но прошлые ошибки и точность не восстанавливаются из отсутствующих данных. До первого нового ответа точность обозначается как отсутствующая, а не как 0%.

### Игры по стадиям взросления

На лужайке питомец ведёт себя по-разному: яйцо слегка покачивается, малыш учится топать, нюхает траву и подпрыгивает; подросток активно гуляет, взрослый размеренно исследует сад и отдыхает, цветущий сниффер покачивается и разбрасывает лепестки. Питомец разворачивается у края лужайки. Нажатие вызывает радостные прыжки и разлетающиеся пиксельные сердечки с плавным исчезновением (без зависимости от шрифта телефона). Эти анимации не меняют потребности и прогресс и не проигрывают время отсутствия в игре.

При превращении питомца меняется и его игра. Кнопка в саду показывает название текущей игры:

| Стадия | Игра | Что делать |
| --- | --- | --- |
| Малыш, от 30 слов | Найди вкусняшку | Найти три угощения под кустами. Питомец подсказывает, где пахнет вкусным. |
| Подросток, от 60 слов | Прятки | Три раза найти питомца за кустами, деревом или камнем — видны нос и хвост. |
| Взрослый, от 90 слов | Повтори за мной | Повторить три последовательности движений длиной 2, 3 и 4. Показ можно повторять. |
| Цветущий сниффер, от 120 слов | Цветочный сад | Вырастить три цветка: выбрать грядку, посадить семечко, полить и добавить солнышко. |

После завершения восстанавливается настроение, результат автоматически сохраняется. Ошибки не штрафуются; можно выйти в сад в любой момент, но незаконченная игра не даёт награды. Цветы в мини-игре декоративные: постоянные растения сада по-прежнему открываются за изученные слова. До вылупления игры недоступны.

### Зоопарк существ

Кнопка **ЗООПАРК** в саду открывает коллекцию из шести друзей. Они появляются строго по очереди:

**Сниффер → Аксолотль → Лиса → Пчела → Черепаха → Эллей.**

Чтобы поселить питомца в зоопарке и открыть следующего, нужно выучить все 150 слов его набора, вырастить питомца и сдать итоговый тест. Переезд подтверждается отдельной кнопкой в зоопарке, а не происходит посреди урока. Незаконченный урок или проверку нужно сначала завершить. Изначально все шесть мест показывают яйца; взрослый вид появляется после переселения выращенного питомца. На лужайке видны промежуточные стадии роста. Яйца следующих существ отмечены маленьким замочком: они видны, но выращивать можно только текущего друга.

У каждого следующего питомца новый набор слов; предыдущие карточки не удаляются. Слову нужны правильные ответы в двух разных раундах. У каждого друга своё вылупление на 30 словах и превращения на 60, 90 и 120 выученных словах. Общий словарь, статистика, результаты проверок и сад **не сбрасываются**; уход нового питомца начинается с полными шкалами. В постоянном саду максимум десять растений, без сброса при смене существа.

В коллекции сохраняются вид и имя выращенного друга. Нажмите на его карточку, чтобы навестить его. После шестого питомца коллекция завершена, новых существ по кругу не выдаётся. Зоопарк и прогресс текущего друга включены в автосохранение и экспорт профиля. Старые профили продолжают игру со своим сниффером.

**Итоговый тест:** десять вопросов из набора текущего существа, минимум семь верных ответов (70%). Ошибки имеют приоритет при повторной попытке. До сдачи следующий питомец закрыт; при неудаче знания и рост не пропадают, тест можно повторять. Ответы, пауза, результат и история попыток сохраняются в профиле. Проверочные ответы не ускоряют рост и не меняют потребности.

**Повторное выращивание:** на карточке выращенного друга есть кнопка с яйцом. После подтверждения можно снова вырастить тот же вид и пройти его слова. Взрослый остаётся виден в зоопарке и рядом с молодым на основном экране. Новый цикл начинается с нулевого роста, но общие знания и статистика сохраняются. Текущий другой питомец с именем, уходом, ростом и итоговым тестом ждёт в сохранённом состоянии. После завершения повтора и теста на 70% он возвращается. Одновременно выращивается только одно новое яйцо; начать второе повторение или переключить питомца посреди урока нельзя. Завершённые повторения увеличивают счётчик выращиваний, а не открывают сразу следующих существ.

**Свой мир для каждого:** сниффер живёт на лужайке; аксолотль — под водой с пузырьками, рыбками, водорослями и кораллами; лиса — на лесной опушке с падающими листьями; пчела — на цветочной поляне с ульем; черепаха — на песчаном берегу с волнами; эллей — в волшебной роще со светлячками. Фон автоматически применяется и к мини-играм. При посещении питомца в зоопарке показывается именно его окружение, а не мир текущего яйца. Фоны кэшируются, а лёгкая анимация не изменяет сохранение.

Мир также развивается с возрастом: у яйца базовое окружение, у малыша появляются новые камушки, у подростка — растения, у взрослого — более крупные детали, у финальной формы — особые украшения. Под водой это кораллы, больше рыбок и сундук; на берегу — ракушки и песчаный замок; на поляне — улей и бабочки; в роще — кристаллы и больше светлячков. Общие садовые растения визуально проявляются постепенно (0/3/6/8/10 по стадиям), но их сохранённое количество не сбрасывается. Стадия фона вычисляется из роста питомца, поэтому переживает перезапуск и начинается заново у нового яйца.

Проверки каждых 30 слов работают и при выращивании новых друзей: рубеж считается по повторённым словам текущего питомца, ошибки из общей очереди по-прежнему имеют приоритет. Результаты записываются отдельно для каждого существа; во вкладке «Проверки» можно переключаться между питомцами стрелками и смотреть прежние результаты.

Пять новых существ нарисованы собственными пиксельными примитивами в `creature_sprites.py`: квадратные формы, тёмный контур, клеточная текстура, прозрачный фон, стадии роста и кадры движения. Отдельная загрузка графики или сеть не нужны.

Взросление меняет не только масштаб, но и рисунок: у аксолотля удлиняются хвост и жабры, появляется спинной плавник; у лисы вырастают уши, мордочка, пушистый хвост и светлая грудка; у пчелы развиваются крылья, полосы и мешочки пыльцы; у черепахи поднимается и усложняется панцирь, затем появляется мох с цветком; у эллея маленькие крылышки превращаются в большие двойные, появляются кристалл и светящиеся искры. Одинаковые цветочные короны заменены индивидуальными финальными деталями.

## Встроенная инструкция

**КАК ИГРАТЬ** на экране входа/регистрации и **СПРАВКА** в саду открывают короткие страницы о возможностях игры: игроки, карточки, рост, уход, проверки, словарик, зоопарк и перенос сохранений. Стрелки переключают страницы, **ПОНЯТНО** возвращает на исходный экран, сохраняя незаконченный ввод имени.

## Игроки, регистрация и сохранение

Как в MathCraft, при первом запуске предлагается создать локального игрока по имени; далее при каждом запуске открывается выбор игрока (последний находится первым в списке). Почта и пароль не нужны, сетевого аккаунта и ограничения доступа к чужой кнопке входа нет — это разделение сохранений на одном устройстве, а не система авторизации.

- Слова, статистика, текущий питомец и его имя, зоопарк, ожидающий питомец при повторном выращивании, уход, сад, уроки, проверки, итоговые тесты и поздравления принадлежат выбранному игроку.
- В шапке показывается имя игрока. **ПРОФИЛЬ → СМЕНИТЬ** сохраняет его состояние и возвращает к выбору; незаконченный урок или тест продолжится после повторного входа. При ошибке сохранения смена игрока блокируется, чтобы не потерять его несохранённый прогресс.
- **ИМЯ ИГРОКА** и **ИМЯ ПИТОМЦА** — отдельные настройки. Одинаковые имена игроков с разным регистром или лишними пробелами не создаются. У нового игрока чистое яйцо, чужие сведения не копируются.
- Старое общее сохранение автоматически становится отдельным игроком **«Сохранённая игра»**. Его можно выбрать и переименовать; регистрация другого ребёнка не присваивает и не стирает старый прогресс.

## Перенос профиля

Имя, изученные слова, стадия питомца, сад и уход сохраняются после каждого игрового действия и при сворачивании. Незаконченный урок продолжается с той же карточки после запуска. Старые сохранения загружаются с именем «Сниффер» по умолчанию; на Android предусмотрен перенос из прежнего каталога приложения.

- На Android сохранение находится в приватном хранилище приложения, на компьютере — в `sniffer_save.json`, в браузере — в localStorage этого сайта. Очистка данных браузера удаляет локальный профиль.
- **ПРОФИЛЬ → ВЫГРУЗИТЬ ПРОФИЛЬ** сохраняет JSON только выбранного игрока, с его именем и идентификатором, без сохранений других детей. На Android открывается системный выбор места, как в MathCraft; в браузере файл скачивается, на компьютере открывается диалог.
- Перед удалением приложения сохраните копию каждого нужного игрока вне каталога игры. После переустановки можно загрузить профиль с экрана выбора, ещё до регистрации.
- Импорт нового игрока создаёт отдельный профиль. Обновление существующего разрешено только после выбора именно этого игрока и подтверждения; чужая копия не заменяет другого ребёнка. Старые файлы без имени тоже принимаются: на экране входа сначала нужно назвать игрока для копии, а внутри выбранного профиля — подтвердить замену только его состояния.
- APK следует обновлять поверх установленного приложения, без удаления и очистки данных. Идентификатор пакета не меняется; Actions сохраняет debug-ключ в кэше для последующих сборок. Если кэш ключа удалён или старый APK подписан другим ключом, Android может потребовать переустановку — для этого нужна выгруженная копия профиля. Debug-кэш не заменяет постоянный релизный ключ.

## Локальный запуск

Требуется Python 3.12 и `pygame-ce` (обычный `pygame` также подходит для локального просмотра).

```powershell
python -m pip install -r requirements.txt
python main.py
```

На Android слова озвучивает системный английский TTS через PyJNIus: инициализация и воспроизведение выполняются в UI-потоке Android. Если английского голоса нет, игра подсказывает скачать его в системных настройках синтеза речи. В Windows используется системный английский голос через `System.Speech`, в браузере — Web Speech API. Также поддерживаются локальные WAV-файлы из `assets/audio`. Если озвучка недоступна, карточка показывает ошибку, а не молча игнорирует кнопку.

## Android

В GitHub Actions есть отдельный workflow **Build Android Debug APK**, как в MathCraft. После отправки изменений в `main` откройте **Actions → Build Android Debug APK → Run workflow**. После успешной сборки скачайте APK из артефакта **EnglishCraft-Android-debug** на странице запуска. Сборка запускается только вручную.

Приложение называется **EnglishCraft**. Обычная и адаптивная Android-иконки находятся в `assets/icon*.png`; исходный генератор — `tools/generate_icon.py` (запуск: `python tools/generate_icon.py`). Идентификатор пакета `org.game.sniffergarden`, имена локальных сохранений и формат профиля сохранены для совместимости с прежними версиями Inglish.

`buildozer.spec` использует тот же Android-стек, что и работающий MathCraft: Python 3.10.11, `pygame`, python-for-android v2024.01.21, SDL2, горизонтальная ориентация, arm64-v8a, Android API 34, min API 24 и NDK 25b. Сборка APK запускается из Linux/WSL с установленным Buildozer:

```bash
buildozer -v android debug
```

На этой машине Android-сборка пока не запускалась; локальная версия проверяется отдельно. Звук необходимо проверить на самом Android-устройстве. В релизе нужно заменить эскизные спрайты на выровненные игровые кадры и проверить озвучку каждого слова.

В карточках новых слов вместо питомца показываются пиксельные ассоциации: животные, еда, предметы, числа, части тела, одежда, погода, эмоции и действия (`word_pictures.py`). Иконки рисуются локально, а не берутся из шрифта эмодзи или сети. В первом наборе проиллюстрировано больше ста слов; правила заменяют картинку у служебных слов. Для пока не проиллюстрированных слов предлагается придумать собственный пример, без случайной картинки не по смыслу. Яйцо и вылупление остаются на экране питомца и в результатах обучения, а не подменяют изображение нового слова.

## Запуск в браузере телефона как у MathCraft

В проект добавлены `pygbag.ini` и совместимые с MathCraft версии из `requirements-web.txt`. После установки зависимостей можно запустить локальный веб-сервер:

```powershell
$env:PYTHONUTF8 = "1"
python -m pip install -r requirements-web.txt
python -m pygbag --ume_block 0 .
```

Для готовой веб-сборки используйте `python -m pygbag --build --ume_block 0 .`; результат появится в `build/web`. Браузерная версия использует Web Speech API для озвучки. Веб-сборка на этой машине пока не проверялась.

Как и в MathCraft, `.github/workflows/build.yml` собирает игру и публикует её в GitHub Pages после push в ветку `main` (если Pages включены в репозитории).
