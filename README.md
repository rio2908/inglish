# Сниффер и сад слов

Первый игровой прототип для Android: 150 английских слов, пять крупных стадий питомца, пять кадров вылупления, кормление, игра, уборка и сад. Графика — крупные квадратные пиксели с видимой клеточной сеткой.

Словарь разбит на десять глав: в нём есть простые приветствия (`hello`, `bye`), короткие слова для первых фраз (`I`, `is`, `and`) и знакомые ребёнку темы — животные, сад, еда, дом, семья, цвета, действия и чувства. Артикли не изучаются как отдельные слова. Русская запись произношения служит подсказкой; образец звучания даёт английская озвучка.

## Игра

- Первые пять правильных ответов постепенно раскалывают яйцо и выпускают малыша.
- Слово считается выученным после правильного ответа в двух разных игровых раундах.
- Каждые пять выученных слов заполняют клетку индикатора, каждые 15 дают снифферу возможность найти растение и открыть короткую историю.
- На 40, 80 и 120 выученных словах сниффер меняет форму. После 120 слов с выросшим питомцем можно закончить сад.
- После вылупления нужно кормить питомца, играть с ним и убирать за ним. Потребности меняются только во время игры. Прогресс слов не пропадает.

## Локальный запуск

Требуется Python 3.12 и `pygame-ce` (обычный `pygame` также подходит для локального просмотра).

```powershell
python -m pip install -r requirements.txt
python main.py
```

На Android слова озвучивает системный английский TTS через PyJNIus. На компьютере приложение может воспроизводить локальные WAV-файлы, если они добавлены в `assets/audio`, но сейчас таких файлов в проекте нет.

## Android

В GitHub Actions есть отдельный workflow **Build Android Debug APK**, как в MathCraft. После отправки изменений в `main` откройте **Actions → Build Android Debug APK → Run workflow**. После успешной сборки скачайте APK из артефакта **SnifferGarden-Android-debug** на странице запуска. Сборка запускается только вручную.

`buildozer.spec` использует тот же Android-стек, что и работающий MathCraft: Python 3.10.11, `pygame`, python-for-android v2024.01.21, SDL2, горизонтальная ориентация, arm64-v8a, Android API 34, min API 24 и NDK 25b. Сборка APK запускается из Linux/WSL с установленным Buildozer:

```bash
buildozer -v android debug
```

На этой машине Android-сборка пока не запускалась; локальная версия проверяется отдельно. Звук необходимо проверить на самом Android-устройстве. В релизе нужно заменить эскизные спрайты на выровненные игровые кадры и проверить озвучку каждого слова.

На карточках пока стоят общие пиксельные сцены главы. Отдельные иллюстрации для всех 150 слов ещё не подготовлены.

## Запуск в браузере телефона как у MathCraft

В проект добавлены `pygbag.ini` и совместимые с MathCraft версии из `requirements-web.txt`. После установки зависимостей можно запустить локальный веб-сервер:

```powershell
$env:PYTHONUTF8 = "1"
python -m pip install -r requirements-web.txt
python -m pygbag --ume_block 0 .
```

Для готовой веб-сборки используйте `python -m pygbag --build --ume_block 0 .`; результат появится в `build/web`. Браузерная версия использует Web Speech API для озвучки. Веб-сборка на этой машине пока не проверялась.

Как и в MathCraft, `.github/workflows/build.yml` собирает игру и публикует её в GitHub Pages после push в ветку `main` (если Pages включены в репозитории).
